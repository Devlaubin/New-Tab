Comment utiliser New Tab

Guide complet pour découvrir toutes les fonctionnalités

📝 Prendre des notes

  1. La zone de notes se trouve en bas de la page
  2. Écrivez vos notes directement dans la zone de texte
  3. Vos notes sont sauvegardées automatiquement
💡 Vos notes sont privées et stockées uniquement sur votre appareil

🔍 Faire une recherche

  1. Tapez votre recherche dans la barre de recherche centrale
  2. Appuyez sur Entrée pour lancer la recherche
  3. Utilisez les flèches directionnelles pour naviguer dans les suggestions

⭐ Ajouter des raccourcis

  1. Cliquez sur le bouton "+" dans la section raccourcis
  2. Entrez le nom du site (ex: GitHub)
  3. Entrez l'URL du site (ex: https://github.com)
  4. Cliquez sur "Ajouter" pour sauvegarder
💡 Vous pouvez ajouter jusqu'à 8 raccourcis sur la page

⚙️ Personnaliser la page

  1. Ouvrez le menu en cliquant sur les trois lignes en haut à gauche
  2. Dans la section "Apparence", vous pouvez:
    • Changer le thème de couleur
    • Activer ou désactiver le mode sombre
  3. Dans la section "Affichage", vous pouvez choisir d'afficher:
    • L'heure
    • La météo
    • Les notes
    • Les raccourcis

🌤️ La météo

  1. Activez la météo dans les paramètres d'affichage
  2. La météo utilise votre position pour afficher les informations locales
  3. Cliquez sur la météo pour voir les prévisions sur 7 jours

🔒 Confidentialité

  1. Vous pouvez activer la recherche privée dans les paramètres
  2. Cette fonctionnalité utilise DuckDuckGo pour une recherche anonyme
  3. Vos données de recherche ne sont pas enregistrées
💡 New Tab ne collecte pas vos données de recherche

⌨️ Raccourcis clavier

  • / - Mettre le focus sur la recherche
  • Esc - Fermer un modal
  • Alt + S - Ouvrir les paramètres
